/ How it works

Scroll through a day with mcpy.

From picking a model to plugging in your own tools — here's how mcpy fits into the rhythm of your day.

01 / 05  ·  Home
One place to start

Pick a model, or let Auto decide.

Your favorite frontier models live side by side. Start typing and mcpy's router picks the right one — or tap a specific brain when you know what you want.

Auto routing 9+ models Smart fallbacks
02 / 05  ·  Compose
Ask anything

One prompt, all your context.

Summarize emails, pull meeting notes, draft a todo — mcpy fans out to the right tools and models behind the scenes, then returns one clean answer.

  • ✓ Streams from multiple sources in parallel
  • ✓ Voice, keyboard and share-sheet input
  • ✓ Remembers recent context across chats
03 / 05  ·  Rich replies
Beyond text

Text, images, code — all in one thread.

Generate a hero image with Gemini, a spec with Claude and ship-ready code with GPT. Swap models mid-conversation without losing the thread.

Image gen Code blocks File uploads Rerun in another model
04 / 05  ·  Connectors
Your apps, connected

Plug in the tools you already use.

One-tap connectors for Gmail, Drive, Calendar, Notion and more. Toggle them on or off per chat so the model only sees what it needs.

  • ✓ OAuth handled in-app, tokens stored on-device
  • ✓ Granular per-chat permissions
  • ✓ Revoke any connector with one tap
05 / 05  ·  MCP Servers
Bring your own tools

Add any MCP server. Yes, any.

mcpy speaks the open Model Context Protocol. Paste a URL, add an auth header if you need one, and the model gets new capabilities instantly — no app update required.
